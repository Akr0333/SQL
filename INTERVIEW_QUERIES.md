# 🎯 SQL Interview Practice — Data Analyst

## Core
1. Find total revenue.
2. Find the top 5 products by revenue.
3. Find customers with more than one order.
4. Calculate average order value.
5. Find revenue by region.

## Intermediate
6. Find each customer's lifetime spend.
7. Find the highest-revenue product in each category.
8. Calculate monthly revenue.
9. Calculate month-over-month revenue growth.
10. Find customers whose spending is above the overall average customer spend.
11. Find products that have never been ordered.
12. Find the percentage of revenue contributed by each category.

## Advanced
13. Use a window function to rank customers by spend within region.
14. Use `LAG()` to compare each month's revenue with the previous month.
15. Use a CTE to calculate customer spend and then segment customers into Low / Medium / High value.
16. Find the first order date for every customer.
17. Calculate each customer's days between first and latest order.
18. Find the top 3 products in every category.
19. Identify repeat customers and their repeat-purchase rate.
20. Build a monthly KPI query containing revenue, orders, customers and average order value.

## What an interviewer is testing
- Can you choose the correct grain?
- Do you understand JOIN cardinality?
- Can you avoid double counting?
- Can you explain why a CTE or window function is useful?
- Can you translate a business question into a measurable KPI?
- Can you validate whether the output makes sense?

## Interview rule
Do not only explain syntax. Explain:

**Business question → data needed → join path → aggregation → validation → insight.**
